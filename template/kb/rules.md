# Rules

What can disqualify the team. Each line names the document it comes from, in `sources/`.

- Deadline: not set yet. When is the last moment to submit, and where?
- Build window: may any code exist before hacking starts?
- Repo: must the project repo be public, and when must it be created?
- Team size: how many people, and must everyone be registered?
- Code origin: what may be reused (templates, libraries, earlier projects)?
- Tools: anything banned or required (hosted models, hardware, sponsor APIs)?

## Where the documents disagree

List each version with its source and the one the team settled on. Ask an organizer and record the answer in [[kb/open-questions]].
