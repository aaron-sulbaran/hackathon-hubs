# Knowledge base index

The pages every hub starts with, one line each with what it answers. Read this first, then only the pages your task touches.

For every page, including the ones the team adds later, run `./hub kb` (or `./hub kb <word>` to search). It reads each page's title and `summary:` line, so a new page needs no line here: write it with a `summary:` in its frontmatter and commit it with `./hub learn kb/<page>.md "<what changed>"`. Two people adding pages at once then never edit the same file.
